- **定义**：脂质中多不饱和脂肪酸的氧化变质。
- 从反应本质上说，脂质过氧化是典型的活性氧参与的自由基链式反应

| 概念       | 核心事实                                                                                                                     |
| -------- | ------------------------------------------------------------------------------------------------------------------------ |
| **自由基**  | 含不成对电子的原子/原子团，因电子急于配对而**反应性极强、寿命短**；通过分子均裂产生。                                                                            |
| **活性氧**  | 高反应性的含氧分子（如O₂•⁻、•OH、H₂O₂、¹O₂）；**氧中毒的机制**正是体内氧大量转化为活性氧，进而攻击细胞膜、蛋白质、酶和DNA。                                                 |
| **链式反应** | 自由基反应最突出的特点，分三阶段——**引发**（产生初始自由基L•）、**增长**（L•与O₂生成LOO•，LOO•再与LH反应再生L•，形成自催化循环）、**终止**（两自由基偶联终止，但因自由基浓度低，自发终止极少，需抗氧化剂介入）。 |
	生物膜中的多不饱和脂肪酸（LH）在活性氧（如•OH）作用下被抽氢，生成脂质自由基（L•），L•迅速与氧反应生成脂质过氧自由基（LOO•），LOO•又攻击另一个脂质分子，再生L•并产生脂质氢过氧化物（LOOH）——如此周而复始，一条链式反应便持续蔓延。由于生物膜富含这类脂肪酸底物，一旦引发，链反应便会不断传播，导致膜脂大量氧化变质，膜结构和功能遭到破坏。而这一链式进程只有在抗氧化剂捕获自由基时才能被有效遏制。
**脂质过氧化的分子机制——它是一个从活性氧引发、经自由基链式自催化传播、最终导致生物膜氧化损伤的级联过程。**
