其他寡糖：
- **[[棉子糖]]**：广泛存在于高等植物中。完全水解会产生葡萄糖，果糖和半乳糖。是一种非还原糖，所有异头碳都参与形成糖苷。结构是Gal($\alpha$ 1->6)Gal($\alpha$ 1<->2$\beta$)Fru.棉子糖家族在植物体内是从头合成的，属于初生寡糖
- **[[水苏糖]]**：是一种四糖，结构为Gal($\alpha$ 1->6)Gal($\alpha$ 1->6)Gle($\alpha$ 1<->2$\beta$)Fru。是棉子糖家族的一员。
通过($\alpha$ 1->6)不断向Glc残基中加入Gal能得到一系列的棉子糖家族成员。其低级产物几乎存在于植物的各个部分，高级同系物一般被限制在贮存器官中。与蔗糖同为糖类的转运与贮存形式
- 人乳中存在二糖到六糖几十种寡糖，多数是含乳糖基的高级寡糖。起作为血型抗原的决定簇作用

### 关于[[环糊精]]
#### 一、它是个什么东西？
环糊精就是 **6~8 个葡萄糖手拉手围成一个圈**。
普通的淀粉是葡萄糖串成一条长链，环糊精是把这条链**首尾接起来**，变成一个环。所以它也叫"环状淀粉"。
- 6 个葡萄糖围成圈 → **α-环糊精**
- 7 个 → **β-环糊精**
- 8 个 → **γ-环糊精**
怎么造出来的？有一种细菌（芽孢杆菌）会分泌一种酶，切淀粉然后把它盘成圈。
#### 二、结构长什么样？像轮胎

这是最关键的：**环糊精分子的形状像个轮胎或甜甜圈**。
葡萄糖的骨架搭成了轮胎的外缘，所有羟基（—OH，喜欢水的东西）全部**朝外**，而轮胎**内部是碳氢骨架——完全疏水**。

```
      外圈：全是羟基 → 亲水 → 能溶于水
      ↓
     ╭―――――――――――――――――╮
    ╱   内腔：碳氢骨架    ╲
   │    → 完全疏水         │
    ╲                     ╱
     ╰―――――――――――――――――╯
```

**这个"外亲水 + 内疏水"的设计是它所有功能的物理基础。**
#### 三、它能干什么？把"怕水"的东西塞进肚子里
环糊精的疏水内腔可以**从水里把疏水分子"吸"进去**，像个分子级的收纳盒：
```
水溶液中的疏水分子        环糊精包住它
      💊
      ↓
   ╭――――――╮         ╭――――――╮
  ╱  💧💧  ╲       ╱ 💊 ╲
 │  💧💊💧  │  →  │ 💧💧 │
  ╲  💧💧  ╱       ╲    ╱
   ╰――――――╯         ╰――――――╯
```

包进去之后：

| 效果 | 原理 |
|------|------|
| **不怕光了** | 被环糊精挡着，光照不到 |
| **不怕热了** | 被兜住，不容易热分解 |
| **不怕氧气了** | 被隔离，氧化不了 |
| **本来不溶于水的能溶了** | 环糊精外皮亲水，带着肚子里的疏水物一起溶 |
| **香味、味道更持久** | 挥发性的香精被锁住，慢慢释放 |
#### 四、实际用在哪？
**食品**：保护香精、色素、维生素不氧化不变味；把姜黄素之类难溶于水的东西变成可溶的。
**药品**：把难溶的药物包住增溶、保护活性成分、控制释放速度。
**化妆品**：稳定香料，让活性成分缓慢释放。
#### 五、还有一个巧妙的用途——分离手性分子
**内壁全是被葡萄糖手性碳包围的**，所以内腔本身是手性的（有左/右偏向）。
两个互为镜像的分子（比如一个 D 型和 L 型），一个能舒服地滑进轮胎里，另一个因为手性不匹配进不去。
把 β-环糊精装进层析柱里：
> 混合物倒进去 → 手性匹配的分子被轮胎兜住流得慢 → 不匹配的直接流走 → 完美分离

这对药物行业极其重要——很多药只有一种手性有效，另一种有毒。
#### 六、它还能当"人造酶"
有实验发现环糊精能大幅加速某些反应：
- α-环糊精让苯酯水解 **快了 300 倍**
- β-环糊精让焦磷酸酯水解 **快了 200 多倍**
为什么？因为它把底物分子**抓进内腔，摆好姿势让水解更容易发生**——和真正的酶做的事一模一样。所以环糊精是研究**模拟酶（人造酶）**的热门骨架。
