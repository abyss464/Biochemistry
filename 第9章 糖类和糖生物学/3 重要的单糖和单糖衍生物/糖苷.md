本段介绍配基为**类固醇、苯并吡喃或含氮碱**的糖苷，这类糖苷多具苦味或特殊香气，微量可药用。
### 一、[[强心苷]]（Cardiac Glycoside）

#### 定义与来源

- 是治疗**充血性心力衰竭和心律障碍**的重要药物
- 广泛存在于植物中，如**毛地黄属**（_Digitalis_）、**毒毛旋花属**（_Strophanthus_）

#### 基本结构特征

| 部分     | 组成                            |
| ------ | ----------------------------- |
| **糖基** | 单糖、双糖或三糖（单糖单位多为**2,6-二脱氧己糖**） |
| **配基** | [[类固醇]]（甾体）结构                 |

> 强心苷的**生理活性主要由配基决定**
![[Pasted image 20260515134833.png]]
#### 配基（强心内酯）的结构特点

- 甾体四环结构中：
    - A、B环：**顺式**稠合
    - B、C环：**反式**稠合
    - C、D环：**顺式**稠合
- C3羟基：β取向
- C14羟基：**总是β取向**
- C17β位：有一个**丁烯羟酸内酯环**（五元内酯环，灰色部分）

#### 代表药物一：[[毛地黄毒苷]]（Digitoxin）

- 糖基：**三个D-毛地黄毒素糖**通过β-1,4糖苷键连接
- 配基：**毛地黄毒苷配基**（digitoxigenin）
    - 即3β,14-二羟-5β,20[22]-强心内酯

#### 代表药物二：[[乌本苷]]（Ouabain）

- 又称G-毒毛旋花苷
- 来源：最初从东非**苦毒毛旋花**（_Strophanthus gratus_）提取，索马里人曾用作**箭毒**
- 糖基：**α-L-鼠李糖**残基
- 配基：**乌本苷配基**（ouabagenenin）
- 重要药理作用：是 **Na⁺,K⁺-ATP酶的强抑制剂**
    - 该酶负责催化Na⁺和K⁺的跨膜运输，维持细胞电解质平衡
    - 抑制此酶 → 影响心肌收缩力

### 二、[[皂苷]]（Saponin）

- 配基为**多环三萜或类固醇**，糖基为寡糖
- 分子同时含有：
    - **亲脂性配基** → 疏水端
    - **亲水性糖基** → 亲水端
- 表现出**去污剂性质**：水溶液振荡时形成**稳定泡沫**
- 强心苷也可归入皂苷类
- 广泛存在于高等植物，药用植物中含量丰富： **人参、柴胡、桔梗、甘草**等

---

### 三、[[花色素苷]]（Anthocyanin）

- 是许多**花和果实着色物质**的糖苷类
- 配基称为**花色素**（anthocyanidin）
- 母体化合物：**2-苯基苯并吡喃[喃]锎**（花[色]锎，flavylium ion）
- 代表：**花青苷**（cyanin），配基为花青素（cyanidin）
- 特点：
    - 花色素本身**难溶于水**
    - 植物中主要以**糖苷形式存在**，增加水溶性
    - 开花植物中种类极多，配基花锎的**3-和5-位OH**可被葡萄糖等糖基化

---

### 核心逻辑总结

```
糖苷（特殊类）
├── 强心苷 → 配基=甾体内酯 → 药用（强心）
├── 皂苷   → 配基=三萜/甾体 → 表面活性，药用
└── 花色素苷 → 配基=苯并吡喃 → 植物色素，增溶
```

> 共同特征：**糖基提供水溶性，配基决定生物活性**
