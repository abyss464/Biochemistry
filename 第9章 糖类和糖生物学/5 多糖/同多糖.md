起贮存作用的同多糖
### [[淀粉]]：
葡萄糖的多聚物，存在：
- 直链淀粉：
	仅少量溶于热水，放置后重新析出淀粉沉淀
- 支链淀粉：
	较易溶于水，形成稳定胶体。是高度分支（24～30个分支一次）的，在分支点存在($\alpha$ 1->6)连接。
多数淀粉的两者之比为1:4。淀粉链是有极性的起始端是还原端，末端是非还原端，支链淀粉具有多个非还原端，但是只有一个还原端。淀粉会形成螺旋结构，双螺旋结构甚至进一步折叠成聚簇结构。

在酸或淀粉酶的作用下被逐步降解，形成各种大小不一的产物，统称[[糊精]]

### [[糖原]]：
结构与支链淀粉一致，但分支程度更高（8～12个分支一次）。聚集体除了糖本身外，还含有分解糖原所需要的酶类。
分支更多->更能快速分解成葡萄糖

合成聚合物的原因：减少葡萄糖的渗透压
### [[右旋糖酐]]：
或称**葡聚糖**是一类由细菌和酵母产生的贮存或胞外黏着多糖，主链以 
α-1,6 糖苷键连接葡萄糖，并带有 α-1,3 等分支。工业上可用明串珠菌发酵蔗糖生产，分子量范围极广。人口腔中的某些细菌也能利用蔗糖合成右旋糖酐，它是牙斑的主要成分，因此蔗糖摄入备受营养学家关注。右旋糖酐经表氯醇交联后可制成不溶性网状结构的珠状凝胶（商品名 Sephadex），通过调控交联比例形成不同孔径，广泛用于蛋白质的分子排阻层析分级。

起结构作用的同多糖
### [[纤维素]]：
生物圈最丰富的有机物质，占植物界碳素的50%以上。纤维素中的葡萄糖基是$\beta$型的，比淀粉中更加稳定。这使平行链通过氢键形成片层结构，若干个分子结构并排聚集形成类晶体的分子束**微纤维**，该结构包埋在果胶，半纤维素，木质素，和伸展蛋白所形成的基质中，增强细胞壁的抗张强度和机械性能。大多数动物缺乏断裂此键的酶，所以不能利用其中的能量。不能被人体消化的食物成分被称为膳食纤维，包括：**纤维素**和**半纤维素**，能促进结肠规律运动；**木质素**，不溶性酚类聚合物，能结合并清除胆固醇；**果胶**和**树胶**等
### [[壳多糖]]：
| **定义与化学组成**     | 壳多糖也称几丁质或甲壳质，是N-乙酰-β-D-葡糖胺的线型同多糖，相对分子质量可达数百万                                                 |
| --------------- | -------------------------------------------------------------------------------------------- |
| **与纤维素的化学差异**   | 唯一差别在于每个残基的C2上的羟基被乙酰化的氨基所取代                                                                  |
| **结构特点**        | 伸展型的带状物，以片层结构存在                                                                              |
| **三种链排列形式**     | ① **α-壳多糖**：所有链平行排列<br>② **β-壳多糖**：链反平行排列<br>③ **γ-壳多糖**：平行片层与反平行片层交替堆叠<br>同一生物中可同时存在三种形式    |
| **与纤维素的排列对比**   | 天然纤维素可能只有平行排列方式；壳多糖则有三种排列形式                                                                  |
| **自然界分布与丰度**    | 广泛分布于生物界，是自然界第二丰富的多糖（仅次于纤维素），年产量约一百万吨                                                        |
| **存在部位**        | ① 大多数真菌和一些藻类细胞壁成分（常代替纤维素或其他葡聚糖）<br>② 主要存在于无脊椎动物中：昆虫、蜘蛛、虾蟹等甲壳类、螺蚌等<br>③ 节肢动物门和软体动物门外骨骼的主要结构物质 |
| **与矿化的关系**      | 在外骨骼中作为矿化基质，类似脊椎动物骨骼中胶原蛋白的作用                                                                 |
| **进化对比**        | 脊椎动物：胶原蛋白基质 → 内骨骼<br>无脊椎动物：壳多糖基质 → 外骨骼                                                       |
| **消化特性**        | 不被脊椎动物消化（与纤维素相同）                                                                             |
| **脱乙酰壳多糖（壳聚糖）** | 壳多糖去乙酰化形成聚葡糖胺                                                                                |
| **脱乙酰壳多糖的应用**   | 因阳离子性质和无毒性，广泛用于：水和饮料处理、化妆品、制药、医学、农业（种子包衣）、食品和饲料加工等                                           |
