天冬氨酸蛋白酶是一个产生于哺乳动物，霉菌，高等植物的蛋白水解酶家族。
- 活性中心存在两个Asp

| 名称                       | 来源         | 功能                    |
| ------------------------ | ---------- | --------------------- |
| 胃蛋白酶（pepsin）             | 动物胃        | 消化食物蛋白                |
| 凝乳酶（chymosin）            | 动物胃        | 消化食物蛋白                |
| 组织蛋白酶D（cathepsin D）      | 脾，肝和其他动物组织 | 溶酶体蛋白消化               |
| 肾素（renin）                | 肾          | 转化血管紧张肽原称为血管紧张肽1；调节血压 |
| HIV-1蛋白酶（HIV-1 protease） | AIDS病毒     | 加工AIDS病毒蛋白            |
攻击思路与丝氨酸蛋白酶类似，但是以两个天冬氨酸为核心形成的催化二联体保守结构为核心。

---
AIDS的HIV-1蛋白酶结构与其他天冬氨酸蛋白酶类似，根据此蛋白酶的非共价四面体过渡态复合物设计的蛋白酶抑制剂已经成为治疗AIDS的有效药物
