# 核酶 ribozyme

> **有催化活性的 RNA**。打破"酶都是蛋白质"的旧观念——证明 RNA 既能存信息、又能催化，是 **RNA world 假说**的关键证据。教材印刷 443 页。

## 定义与意义

- **核酶 = 具催化功能的 RNA**（ribozyme = ribonucleic acid + enzyme）。
- 催化机制：靠**特定空间折叠**形成活性中心，把底物结合、定向排列、提供反应条件（如疏水环境）。
- **常需金属离子辅助**：RNA 反应基团远少于蛋白，故多借 **金属离子**（也可借碱基、氨基酸、咪唑等小分子）作辅助因子。
- 存在形式：单独的 RNA，或 RNA–蛋白复合物。
- ⭐ 意义：酶不一定是蛋白；支持"最早的生命用 RNA 同时管遗传与催化"（RNA world）。

## 主要种类

| 核酶 | 大小 | 来源 / 备注 |
|---|---|---|
| **23S rRNA**（肽酰转移酶） | 大 | 核糖体大亚基，**催化肽键** → 核糖体是核酶⭐ 见 [[rRNA]] |
| **锤头核酶** hammerhead | ~40 nt | **已知最小的核酶**⭐；3 个螺旋区 + 保守连接区；类病毒常见 |
| **发夹核酶** hairpin | ~70 nt | 烟草环斑病毒卫星 RNA (sTRSV) |
| **斧头核酶** axe / HDV | ~90 nt | 人丁型肝炎病毒；由 2 个**假结**构成（见 [[RNA的高级结构]]） |
| **VS 核酶** | ~160 nt | 链孢霉线粒体；多茎环组成 |
| **自我剪接内含子** | — | I 型 / II 型 |
| **RNase P 的 RNA 亚基（M1 RNA）** | — | 催化 tRNA 前体 5′端加工 |

## 应试提示

- 名词解释：**核酶 = 有催化活性的 RNA**；意义 = 酶≠都是蛋白、RNA world 证据。
- 数字/之最：**锤头核酶 ~40 nt = 最小核酶**；**核糖体（23S rRNA）= 肽酰转移酶**。
- 常考实例串："核酶有哪些？"→ 23S rRNA、锤头、发夹、I/II 型内含子、**RNase P (M1 RNA)**。
