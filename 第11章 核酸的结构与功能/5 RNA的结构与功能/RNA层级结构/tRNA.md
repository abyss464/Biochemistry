# tRNA（转运 RNA）

> 三类RNA一级结构里的**第一块**。功能：转运氨基酸、识别密码子。

## 一级结构特征

- 最小的 RNA：**60~95 个核苷酸**（酵母丙氨酸 tRNA = **76 nt**，第一个被测序的 RNA）。
- 相对分子质量约 **25000**，沉降系数 **4S**。
- **稀有碱基最多**：可达碱基总数的 **10%~15%**（增加识别与疏水作用）。
- 末端固定：**3′端皆为 CCA-OH**（氨基酸挂在这里）；5′端多为 pG。
- 含一些**保守序列**，与其特殊结构功能有关。

## 高级结构特征

> 通用层级（茎环/G·U/假结/RNP）见 [[RNA的高级结构]]；这里是 tRNA 的具体范例。教材印刷 440~441 页。

### 二级结构 —— 三叶草形
<img src='Pasted image 20260617173857.png' width=80%>
> 课本**图 11-19**：三叶草二级结构平面图（R=嘌呤、Y=嘧啶、ψ=假尿苷、●螺旋区、*修饰碱基）。

记忆框架：**四臂四环**（一个氨基酸臂 + 四个茎环）。数字就是得分点：

| 部位                      | 关键数字 / 特征                      | 要点                   |
| ----------------------- | ------------------------------ | -------------------- |
| **氨基酸臂** (acceptor arm) | **7 对碱基**；5′-磷酸，**3′-CCA-OH**  | CCA-OH = **接氨基酸**位点⭐ |
| **DHU 环 / D 环**         | 8~12 nt，含 2 个**二氢尿嘧啶**；茎 3~4 对 | 名字即来自 DHU            |
| **反密码子环**               | **7 nt，正中 3 个 = 反密码子**；茎 5 对   | 识别 mRNA 密码子⭐         |
| **额外环 / 可变环**           | 3~18 nt，大小不定                   | tRNA 分类靠它            |
| **TψC 环 / T 环**         | 7 nt（含假尿苷 ψ）；茎 5 对             | ψ = 修饰碱基代表           |

> 速记：四环里**三个是 7 nt**（反密码子环、TψC 环明确为 7，DHU 环略多）；茎多为 **5 对**，氨基酸臂 **7 对**。

### 三级结构 —— 倒 L 形（图11-20）

![[tRNA_1EHZ.png]]
> PDB **1EHZ**（酵母苯丙氨酸 tRNA）顶视渲染，两臂成直角。
> **配色图例**：🔵蓝 = acceptor + TψC 臂（L 的"一横"）；🟢绿 = D + 反密码子臂（L 的"一竖"）；🟠橙 = **3′-CCA 接氨基酸端**；🔴红 = **反密码子(34-36)**。两功能端分处 L 两个远端 → 读码与接氨基酸互不干扰。
> ⚠️ 真实 3D 比课本简笔图拥挤（臂是弯的双螺旋、肘部松散），课本"三叶草/倒 L"是简化示意，答题按简化图即可。

- **1974 年 S.H. Kim** 用 X 射线衍射测**酵母苯丙氨酸 tRNA**，揭示倒 L 形。⭐（人名+年份+哪种 tRNA 常考）
- 折叠方式：三叶草平面对折拼成倒 L——
  - **一横** = 氨基酸臂 + TψC 茎环 接成连续双螺旋
  - **一竖** = DHU 茎环 + 反密码子茎环 接成连续双螺旋
  - 两个功能位点被拉到两端：**一端 3′-CCA-OH（接氨基酸）、另一端反密码子（读 mRNA）**，互不干扰。
- 维持力：**相邻碱基疏水堆积为主**（见 [[RNA的高级结构]]）＋ 非常规氢键（非 W-C 碱基对、碱基-骨架、第三碱基-碱基对）；**大量修饰核苷酸**也参与折叠并增强识别。

> [!warning] 易混
> 二级 = **三叶草**，三级 = **倒 L**，别答反。三叶草是"平面配对图"，倒 L 是它"对折后的空间形"。

### 层级小结

| 层级 | tRNA 体现 | 维持力 |
|---|---|---|
| 一级 | 序列 + 大量修饰碱基 | 磷酸二酯键 |
| 二级 | **三叶草形**（四臂四环，含 G·U） | 氢键配对 |
| 三级 | **倒 L 形**（1974 Kim, 酵母 Phe-tRNA） | 碱基堆积为主 + 非常规氢键 |

## 应试提示

- 数字必记：**4S、60~95 nt、稀有碱基 10~15%、3′-CCA-OH**。
- 结构必记：二级 = **三叶草**（四臂四环），三级 = **倒 L**（1974 Kim, 酵母 Phe-tRNA）。
- tRNA 修饰**甲基化多在碱基**（对比 [[rRNA]] 多在核糖）。
