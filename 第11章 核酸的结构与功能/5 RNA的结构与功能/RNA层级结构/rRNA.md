# rRNA（核糖体 RNA）

> 三类RNA一级结构里的**第二块**。含量最多（约占细胞 RNA 的 80%）。

## 一级结构特征（各组分大小与修饰）

| 组分   | 核苷酸数 | 原核 / 真核   | 修饰特点                        |
| ---- | ---- | --------- | --------------------------- |
| 5S   | 120  | 原核 + 真核都有 | **无稀有碱基**（基本不修饰）            |
| 5.8S | 160  | **真核特有**  | 含 ψ、Gm/Um；与原核 5S 有共同序列，功能相似 |
| 16S  | —    | 原核小亚基     | ~10 个甲基化核苷                  |
| 23S  | —    | 原核大亚基     | ~20 个甲基化核苷                  |
| 18S  | —    | 真核小亚基     | 40 多个甲基化核苷                  |
| 28S  | —    | 真核大亚基     | 70 多个甲基化核苷                  |

**修饰部位对比（高频简答）**：rRNA 甲基化多在**核糖**（2′-O-甲基），[[tRNA]] 多在**碱基**；真核 rRNA 修饰多于原核。

> [!warning] 易混
> 5S 原核真核**都有**；5.8S **只真核**。别答反。

## 高级结构特征

> 教材印刷 443 页。本节灵魂是一个**认知翻转**：rRNA 在核糖体里从"骨架/衣架"翻身成**催化主体**——核糖体是**核酶**。

### 两个亚基 = 两个功能中心（分工：小读、大接）

核糖体 = **3~4 种 rRNA + 50 多种蛋白**；rRNA 折叠撑起骨架，蛋白多镶在外表面（几乎无蛋白埋入 RNA 内核或两亚基界面）。

| 亚基              | 主角 rRNA                                | 折叠特点         | 功能中心                                                             |
| --------------- | -------------------------------------- | ------------ | ---------------------------------------------------------------- |
| **小亚基**(原核 30S) | **16S**（~46% 碱基配对，约 50 茎环，4 结构域，折叠成花状） | 结构域较**分明**   | **解码中心 (decoding centre)**：读 mRNA 密码子、校验 tRNA 反密码子；含 **A/P/E 位** |
| **大亚基**(原核 50S) | **23S**（6 结构域交织成整体）+ 5S                | 结构域**交织不分明** | **肽酰转移酶中心 (peptidyl transferase centre)**：催化肽键，**只有 RNA、无蛋白**⭐   |

> 抓手：**16S = 解码（读）；23S = 肽酰转移酶（接肽键）**，"读在小、接在大"。

![[rRNA_1FFK_50S.png]]
> PDB **1FFK**（嗜盐古菌 50S 大亚基），隐去蛋白只留 rRNA。**配色**：🔵蓝 = **23S rRNA**（盘绕撑起整个大亚基骨架）、🟠橙 = **5S rRNA**（小，嵌在中央突起处）。直观体现"23S 是核糖体骨架、5S 镶在其中"——蛋白质则贴在这副 rRNA 骨架的外表面。

### 真核 vs 原核 rRNA 对应

| | 小亚基 | 大亚基 |
|---|---|---|
| **原核** | 16S | 23S + 5S |
| **真核** | 18S | 28S + 5S + **5.8S** |

> [!warning] 别答反
> 小亚基 **18S ↔ 16S**；大亚基 **28S ↔ 23S**。**5.8S 真核特有**（与原核 23S 的 5′端同源，推测由其演变而来）。

## 功能

rRNA 除作为**核糖体骨架**外，还与 mRNA/tRNA 作用，**催化肽键形成**。
⭐ 重点：原核 **23S rRNA = 肽酰转移酶**，说明**核糖体是核酶**。深写见 [[核酶 ribozyme]]。

## 应试提示

- 功能中心定位：**16S = 解码中心**、**23S = 肽酰转移酶中心（核酶）**。
- 真核↔原核：**18S↔16S、28S↔23S**；5.8S、5S 归属别答反。
- 核心结论简答："核糖体是核酶吗？"→ 是，**23S rRNA 催化肽键**（H.F. Noller 等，约 2000 年）。
