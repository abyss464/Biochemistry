# mRNA（信使 RNA）

> 三类RNA一级结构里的**第三块**。DNA→蛋白的信使。一级结构 = 编码区 + 非翻译区(UTR)，两端常被特殊修饰。

## 一、顺反子（一条 mRNA 上有几个编码区）

- **顺反子 = 编码一条多肽链的功能单位 ≈ 基因**（由顺反测验界定）。
- **原核**：基因常成组由**操纵子**转录 → **多顺反子 mRNA**（一条 mRNA 多个编码区，区间为 UTR）；单基因则单顺反子。
- **真核**：**一律单顺反子**。
- ⭐ 原核 mRNA（含噬菌体）**无修饰碱基、无帽子、无 poly(A)**。

## 二、3′端 poly(A) 尾（真核）

- 约 **20~250 nt** 腺苷酸串，**转录后**由 **poly(A) 聚合酶**添加（**非模板编码**！）。
- 酶专一作用于 mRNA，对 rRNA/tRNA 无作用。
- 功能：① 助 mRNA 核→质运输；② 与半寿期有关（**新生 mRNA 尾长，衰老的尾短**）。

## 三、5′端帽子结构（重点⭐⭐）

- **连接方式**：5′端倒扣一个**甲基化鸟苷酸 m⁷G**，经焦磷酸以 **5′,5′-三磷酸连接**（方向反常 → 抗 5′-外切酶）。
- **三种类型**（型号数字 = 被甲基化核糖个数）：

| 类型 | 末端核糖甲基化 |
|---|---|
| 0 型 | 0 个 |
| I 型 | 1 个 |
| II 型 | 2 个 |

- 符号读法：m 在字母**左**=碱基甲基化；m 在字母**右**=核糖甲基化。
- 功能：① 抗 5′-外切核酸酶降解；② 助核糖体识别结合 mRNA，正确起始翻译。
- 对比：[[RNA的一级结构]] 末尾——snRNA 帽是**三甲基**(m³,²,⁷G)，mRNA 帽是**单甲基**(m⁷G)。

## 四、原核 vs 真核 mRNA（只记这张就够答题）

| | 原核 mRNA | 真核 mRNA |
|---|---|---|
| 顺反子 | 单 or **多**顺反子 | **只**单顺反子 |
| 5′ 帽子 | **无** | **有**(m⁷G) |
| 3′ poly(A) | **无** | **有**(20~250 nt, 后加) |
| 修饰碱基 | **无** | 偶有极少量 |

## 结构图说明（诚实标注）

mRNA 是**单链、柔性、无稳定特征三级结构**的分子——不像 [[tRNA]]（L 形）、[[rRNA]]（致密折叠）有固定 3D 构象，**单独渲染一个 mRNA 的 cartoon 没有代表性**。
其"结构"要点在一级层面：**5′帽子 + 编码区 + 3′poly(A)**（见教材图 11-16）。
如需 3D，只能放进**核糖体翻译复合物**里看它穿过小亚基解码通道的走向（待补：70S 翻译复合物渲染）。
