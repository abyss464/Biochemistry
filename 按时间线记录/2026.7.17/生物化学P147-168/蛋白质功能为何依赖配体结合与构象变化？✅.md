【印刷第147–150页 · 生物化学上册 第4章导论、一、蛋白质功能的多样性】★名解与简答

蛋白质的功能虽然多样，但有一个共同基础：**特定的三维结构使蛋白质能够选择性、可逆地结合其他分子；结合又能引起构象变化，从而完成催化、转运、信号传递和调节。**

## 配体、结合部位和诱导契合是什么？

- **配体**（ligand）：能够被蛋白质特异、可逆结合的分子，可以是小分子，也可以是另一种蛋白质。
- **结合部位**（binding site）：蛋白质上直接与配体接触的区域。其大小、形状、电荷和亲疏水性与配体互补，因此具有选择性。
- **诱导契合**（induced fit）：配体接近并结合后，蛋白质发生构象变化，使结合部位与配体更加互补的过程。

三者关系是：**配体识别结合部位 → 弱相互作用使二者可逆结合 → 蛋白质发生诱导契合 → 产生或调节功能。**

酶结合并转化的配体称为**底物**（substrate），直接结合底物并进行催化的区域称为**活性部位**（active site）。

## 蛋白质—配体相互作用有哪些共同原则？

1. **特异性**：结合部位与配体在空间形状和化学性质上互补。
2. **可逆性**：结合主要依靠多个弱相互作用，既能稳定识别，又允许配体释放。
3. **构象耦联**：配体结合可引起蛋白质构象变化，并把结合信息传到同一蛋白质的其他部位或其他亚基。

## 蛋白质为什么能够传递和调节结合信息？

构象耦联能够发生，是因为蛋白质不是刚性模型，而是动态分子：

1. 侧链和局部肽段不断发生小幅运动，整个分子也可发生较大的构象改变。
2. 多亚基蛋白中，一个亚基的构象变化可通过亚基界面传给其他亚基。
3. 某一部位结合配体后，如果改变了另一部位的结合或催化能力，称为**别构效应**（allosteric effect）。

## 蛋白质有哪些主要功能？

| 功能 | 作用和代表 |
|---|---|
| 催化 | 酶加快特定化学反应，并可成为代谢调节环节 |
| 信号与信号转导 | 激素、生长因子和受体负责细胞间、细胞内信息传递 |
| 转运 | 运输气体、离子、脂质及其他分子 |
| 结构与支撑 | 构成细胞骨架、结缔组织和保护性结构 |
| 运动与动力 | 将化学能转化为机械运动 |
| 防卫与保护 | 抗体、凝血蛋白和防御性蛋白保护机体 |
| 营养与贮存 | 贮存氨基酸、金属离子等物质 |
| 支架与衔接 | 把多个信号或结构组分组织在一起 |

氨基酸序列的多样性产生三维结构的多样性，进而产生结合特异性和功能多样性。同一种蛋白质也可能同时承担多类功能。
