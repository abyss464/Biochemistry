【印刷第307-311页 · 生物化学上册 第8章五、别构酶实例·ATCase】★★★别构酶范例

**一句话主线**：天冬氨酸转氨甲酰酶（ATCase）是嘧啶(CTP)合成途径的**第一个酶**，被终产物 **CTP 反馈抑制、ATP 激活**；其**催化亚基与调节亚基可分离**，是研究别构调节的经典模型。

## 一、★ 反应与调节逻辑
- 催化：**氨甲酰磷酸 + 天冬氨酸 → N-氨甲酰天冬氨酸**（嘧啶合成第一步）。
- **CTP（终产物）反馈抑制**：负异促效应，降低酶对底物的亲和性、**不改变 Vmax**（K型抑制），抑制可达90%。
- **ATP 激活**：正异促效应，增强对底物亲和性、也不改变 Vmax。**ATP 与 CTP 竞争同一调节部位**（高 ATP 可解除 CTP 抑制）。
- 底物（氨甲酰磷酸 + Asp）结合是**协同的（同促正协同）**，v-[S] 呈 **S形曲线**。
- 生物学意义：ATP 作信号（提供 DNA 复制能量→需要嘧啶）；CTP 反馈抑制保证嘧啶充足时不继续合成。

## 二、★★ 亚基组成（务必背清）
- 用 **对羟汞苯甲酸(pHMB)** 处理（修饰 Cys 巯基）→ ATCase **失去调节活性**（ATP/CTP 不再影响、协同性消失），但**保留全部催化活性、活性还大50%**——即**脱敏**。
- 天然酶 = **c₆r₆**：**2 个催化三聚体(c₃) + 3 个调节二聚体(r₂)**，即 6 条催化链 + 6 条调节链。
  | | 催化亚基(c) | 调节亚基(r) |
  |---|---|---|
  | 组成 | 3 条 c 链 | 2 条 r 链 |
  | 功能 | **有催化活性**、不结合 ATP/CTP、无S形动力学 | **无催化活性**、结合 ATP/CTP |
- 调节链靠 **Zn²⁺ 与 4 个 Cys 配位**的结构域稳定；pHMB 用汞取代 Zn 使调节结构域失稳、导致亚基解离。
- **催化部位和调节部位在不同肽链上**（ATCase 特例，不是所有别构酶都这样）。

## 三、★ 别构机制：T→R 的四级结构大变化
- **PALA**（N-膦乙酰基-L-天冬氨酸）是**双底物过渡态类似物**、强竞争性抑制剂（Kd≈10 nmol·L⁻¹），是研究工具。
- 结合底物/PALA 使酶由 **T态 → R态**：催化三聚体彼此**移开 1.2 nm、绕3重轴旋转 10°**，调节二聚体绕2重轴旋转 15°；**240s 环重定向**释放催化基团、优化活性部位。
- 别构信号**长距离传递**（活性部位间 2.2 nm，CTP结合部位距最近活性部位 >5 nm）——通过肽链界面作为"**分子开关**"传递（类似血红蛋白）。
- 硝基酪氨酸报告基团实验证明：底物类似物琥珀酸结合一个三聚体即改变另一三聚体环境 → **按齐变(MWC)方式发生协同 T→R 转变**；ATP 使平衡移向 R、CTP 移向 T。

> 记忆抓手：**"c₆r₆、CTP抑ATP激竞争调节部位、pHMB脱敏、PALA是过渡态类似物、T→R齐变"**。ATCase 是把"协同性 + 反馈抑制"整合的教科书范例。
