【印刷第305-307页 · 生物化学上册 第8章五、别构模型】★★★对比必考

**一句话主线**：解释协同性有两大模型——**齐变模型（MWC/对称模型）**认为亚基**同步齐变、保持对称、只有T↔R两态**；**序变模型（KNF/诱导契合发展）**认为亚基**逐个转变、有TR杂合态**。核心区别：**能否解释负协同**。

## ★★ MWC vs KNF 全面对比（背这张表）
| | **MWC 齐变模型**（Monod-Wyman-Changeux 1965） | **KNF 序变模型**（Koshland-Némethy-Filmer 1966） |
|---|---|---|
| 别称 | 齐变 / **对称模型** | 序变 / 诱导契合的发展 |
| 无配体时 | **T、R 两态处于平衡**（偏 T 态） | **只有一种构象（T态）** |
| 构象转变方式 | **全部亚基同步齐变**（保持分子对称性） | **逐个序变**（一个结合诱导邻近亚基转变） |
| 有无 TR 杂合态 | **无**（要么全T要么全R） | **有**各种 TR 杂合态 |
| 效应物作用 | 抑制剂稳定 **T态**、激活剂稳定 **R态** | 结合诱导 T→R |
| 能解释正协同 | ✅ | ✅ |
| 能解释**负协同** | ❌ **不能** | ✅ **能** |
| 能解释别构抑制/激活 | ✅（异促可正可负） | ✅ 全都能 |
| 适用 | **底物调节**的别构（同促必为正协同） | 大多数别构酶；**非底物调节**（如钙调蛋白结合Ca²⁺的正协同序变） |

## 关键辨析
- **MWC 的最大局限：不能解释负协同效应**（因同步齐变不允许"结合一个反而降低下一个亲和力"）。
- **KNF 更普适**：亚基间相互作用既可增大也可减小相邻亚基对配体的亲和力 → 同时解释正/负协同、别构抑制/激活。
- 两模型都从不同角度解释协同性，各有局限；真实机制可能更复杂——**某些酶符合序变、某些符合齐变**。

> 记忆抓手：**MWC = "全体立正齐步走、保持对称、只会正协同"；KNF = "一个带一个、有杂合态、正负都行"**。看到"负协同"就排除 MWC。
