【印刷第353-356页 · 生物化学上册 第9章五、细菌细胞壁杂多糖】★★★微生物交叉·必考

**一句话主线**：革兰氏阳性菌=**厚肽聚糖 + 磷壁酸**；革兰氏阴性菌=**薄肽聚糖 + 外膜(含脂多糖LPS)**。肽聚糖主链是 **GlcNAc(β1→4)MurNAc** 交替、靠肽桥交联成刚性囊。

## 一、★★ G⁺ vs G⁻ 细胞壁（务必背清）
| | 革兰氏阳性(G⁺) | 革兰氏阴性(G⁻) |
|---|---|---|
| 肽聚糖 | **多层、厚(10~20nm)** | **单层或几层、薄(~2nm)** |
| 磷壁酸 | **有** | **无** |
| 外膜 | 无 | **有**（磷脂、脂蛋白、膜孔蛋白、**脂多糖LPS**） |
| 革兰氏染色 | 不易脱色（保留紫色） | 易被乙醇脱色 |
| 例子 | 金黄色葡萄球菌 | 大肠杆菌 |

## 二、★★ 肽聚糖(peptidoglycan / 黏肽 / 胞壁质)
- 主链：**N-乙酰葡糖胺(GlcNAc) 与 N-乙酰胞壁酸(MurNAc) 经 (β1→4) 交替**连接。
- 短肽连在 MurNAc 上，链间靠肽交联成刚性囊；四肽氨基酸**D/L 交替**（L-Ala-D-Glu-R-D-Ala）。
- ★ 交联差异：**G⁻(大肠杆菌)** 四肽直接相连（D-Ala 与第3残基侧链氨基）；**G⁺(金葡菌)** 靠**五聚甘氨酸桥**交联。
- ★ **溶菌酶**水解 GlcNAc-MurNAc 间 **(β1→4) 糖苷键**杀菌；**青霉素**干扰肽交联桥形成（抑糖肽转肽酶）→ 细菌失去抗渗透能力。

## 三、★ 磷壁酸(teichoic acid)——只在 G⁺
- 非糖类但相关；主链由**醇(核糖醇/甘油) + 磷酸交替**连接，侧链 D-Ala 或葡萄糖。
- 分**脂磷壁酸**（末端磷酸连质膜糖脂）和**壁磷壁酸**（末端磷酸二酯键连 MurNAc）。
- 作用：负电荷调节离子进出、控制自溶素防溶菌、贮磷、造就**细胞壁抗原特异性**（血清学分型）。

## 四、★ 脂多糖(LPS)——只在 G⁻ 外膜
- 三部分：**脂质A + 核心寡糖 + O-特异链**。
  - **脂质A**：(β1→6) 葡糖胺二聚物 + 磷酸 + 脂肪酸；锚定外膜；是**内毒素(endotoxin)**（G⁻感染性休克/降血压的元凶），对细胞存活**绝对必需**。
  - **核心寡糖**：含 **Kdo**、Hep 和己糖。
  - **O-特异链**：几十个重复寡糖单位，有抗原性=**O-抗原**，是 G⁻ 血清型鉴别依据（沙门氏菌1400多血清型）；含它=S型(光滑菌落，常致病)，缺它=R型(粗糙菌落)。

> 记忆抓手：**"G⁺=厚肽聚糖+磷壁酸;G⁻=薄肽聚糖+外膜LPS;肽聚糖=GlcNAc-β1→4-MurNAc;溶菌酶断糖苷键、青霉素断肽桥;脂质A=内毒素"**。
