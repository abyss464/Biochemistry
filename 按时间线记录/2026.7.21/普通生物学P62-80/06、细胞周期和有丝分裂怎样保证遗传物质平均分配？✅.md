【陈阅增普通生物学印刷P79-82 · 第5章5.1 细胞周期与有丝分裂】★★★细胞分裂·必考

**一句话主线**：细胞周期=**间期(G₁-S-G₂) + 有丝分裂期(M)**；有丝分裂分**前期→前中期→中期→后期→末期**五期,再加胞质分裂,把复制的染色体**平均分到两个子细胞**。

## 一、★★ 细胞周期(cell cycle)
- 定义：从一次分裂开始到下一次分裂开始的全过程。
- 组成：**分裂间期(interphase) + 有丝分裂期(M期)**。
  - **间期** = **G₁期(第一间歇) → S期(DNA合成) → G₂期(第二间歇)**。
  - 离开周期不再分裂的细胞=**G₀期**细胞。
- **原核细胞**用**二分分裂(binary fission)**增殖（真核有丝分裂可能源于此）：复制起点先分开移向两端→质膜内陷分成两个各含一个基因组的子细胞。

## 二、★★ 有丝分裂五期（务必按序背 + 每期关键事件）
| 期 | 关键事件 |
|---|---|
| **前期(prophase)** | **染色质→染色体**(变短变粗,每条含2个姐妹染色单体、共1个着丝粒);**核仁解体、核膜尚在**;微管去组装成库供纺锤体;**中心体**(含中心粒)移向两极、形成星体 |
| **前中期(prometaphase)** | **核膜破碎成小泡**、核纤层解聚;动粒微管连上染色体动粒 |
| **中期(metaphase)** | **各染色体的着丝粒排列到赤道面(equatorial plane)** |
| **后期(anaphase)** | **着丝粒分开、姐妹染色单体分离**,由动粒微管牵引**以相同速度移向两极**;动粒微管缩短、极微管伸长(两极距离加长) |
| **末期(telophase)** | 两组染色体抵两极、动粒微管消失;**核膜重建、核仁重现、染色体解旋成染色质** → 核分裂完成、DNA平均分到两个子核 |

- ★ 三类纺锤体微管：**星体微管**(中心体呈辐射)、**动粒微管**(连中心体与染色体,染色体移动必需)、**极微管**(来自两极、赤道交会)。

## 三、★ 胞质分裂(cytokinesis)——动/植物不同
| | 动物细胞 | 植物细胞 |
|---|---|---|
| 方式 | 赤道处**肌动蛋白微丝环**收缩→**环沟内凹**缢裂成两个 | 内部形成**细胞板(cell plate)**→新细胞壁 |
| 细节 | 环沟在赤道→子细胞等大（偏移则不等大,如极体） | 高尔基体/内质网小泡在赤道面融合成细胞板→向外延伸接原细胞壁;留下**胞间连丝** |

> ★ 意义：有丝分裂保证**每个子细胞得到一组与母细胞相同的遗传物质**（生长、修复、无性繁殖用）。
> 记忆抓手：**"周期=间期(G₁-S-G₂)+M期;有丝分裂五期=前期(染色质→染色体、核仁解体)、前中期(核膜破)、中期(着丝粒排赤道面)、后期(姐妹染色单体分离移两极)、末期(核膜核仁重建);胞质分裂动物缢裂、植物细胞板"**。
