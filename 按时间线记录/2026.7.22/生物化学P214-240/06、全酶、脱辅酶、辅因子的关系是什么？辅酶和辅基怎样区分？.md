从化学组成看，酶分**单纯蛋白质酶**和**缀合蛋白质酶**两类；缀合酶由不表现活性的**脱辅酶**加**辅因子**组成，二者结合成**全酶**才有活性。辅因子按与脱辅酶结合的松紧分为**辅酶**和**辅基**。这张卡承接第5卡，讲“酶由什么组成”。

## 名词解释

- **单纯蛋白质酶**（simple protein enzyme）：除蛋白质外不含其他物质的酶，如脲酶、蛋白酶、淀粉酶、脂肪酶、核糖核酸酶。
- **缀合蛋白质酶**（conjugated protein enzyme）：除蛋白质外还要结合非蛋白的小分子或金属离子的酶。
- **脱辅酶**（apoenzyme）：缀合酶中的蛋白质部分，本身无催化活性。它**决定酶催化的专一性**。
- **辅因子**（cofactor）：缀合酶中的非蛋白部分，包括金属离子和有机化合物，本身也无催化活性。
- **全酶**（holoenzyme）：脱辅酶与辅因子结合后形成的、有催化活性的完整复合物。关系式：**全酶 ＝ 脱辅酶 ＋ 辅因子**。催化时二者必须同时存在，各自单独存在都无催化作用。

## 辅酶和辅基怎样区分（比较维度：与脱辅酶结合的松紧、能否透析除去）

辅因子里的有机化合物又按“与脱辅酶结合的牢固程度”分成辅酶和辅基：

| 比较维度 | 辅酶（coenzyme） | 辅基（prosthetic group） |
|---|---|---|
| 与脱辅酶结合 | 比较松弛（非共价） | 牢固（共价） |
| 能否透析除去 | 能透析除去 | 不能透析除去，需化学处理才能分开 |
| 举例 | 辅酶Ⅰ（NAD⁺）、辅酶Ⅱ（NADP⁺） | 细胞色素氧化酶中的铁卟啉、丙酮酸氧化酶中的 FAD |

两者**并无严格界线**，区别仅在结合的牢固程度。

## 常见辅因子分别携带什么

辅因子不是只负责“陪在酶旁边”，而是在反应中实际转移电子、原子或基团。教材表 6-4、6-5 中最需要建立的对应关系如下：

| 辅因子 | 主要转移对象或典型作用 | 教材中的酶例 |
|---|---|---|
| Zn²⁺ | 参与催化或稳定结构 | 碳酸酐酶、醇脱氢酶、羧肽酶、DNA 聚合酶 |
| Cu²⁺ | 参与氧化还原 | 细胞色素氧化酶、超氧化物歧化酶 |
| Mg²⁺ | 帮助结合、转移含磷基团 | 己糖激酶、丙酮酸激酶 |
| Fe²⁺／Fe³⁺ | 参与氧化还原 | 过氧化氢酶、过氧化物酶、细胞色素氧化酶 |
| TPP | 醛基 | 丙酮酸脱氢酶 |
| FMN、FAD | 氢原子、电子 | 单胺氧化酶等 |
| NAD⁺、NADP⁺ | 氢负离子、电子 | 乳酸脱氢酶、6-磷酸葡糖脱氢酶 |
| CoA | 酰基 | 乙酰 CoA 羧化酶 |
| PLP | 氨基 | 天冬氨酸转氨酶 |
| 生物素 | CO₂ | 丙酮酸羧化酶 |
| 钴胺素辅酶 | 氢原子、烷基 | 甲基丙二酰-CoA 变位酶 |
| 四氢叶酸 | 一碳基团 | 胸苷酸合酶 |
| 硫辛酸 | 酰基 | 丙酮酸脱氢酶 |

这些对应关系还说明：许多维生素之所以重要，是因为它们是辅酶或辅基的前体。

## 三条要记住的机制性结论

1. **脱辅酶决定专一性**：一种脱辅酶往往只认一种辅酶（辅基），换一种就失活（按本教材的例子，谷氨酸脱氢酶需要辅酶Ⅰ，换成辅酶Ⅱ便失活）；但同一种辅酶可与多种脱辅酶结合、催化不同底物（如 3-磷酸甘油醛脱氢酶、乳酸脱氢酶都用辅酶Ⅰ）。
2. **辅酶（辅基）的作用**：在催化中起**传递电子、原子或某些化学基团**的作用。
3. **许多维生素是辅酶（辅基）的前体**。
