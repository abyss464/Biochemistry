**一句话主线**：酶的专一性分**结构专一性**（绝对/相对）和**立体异构专一性**（旋光/几何/A-B型）两大类。解释专一性的假说从刚性的"**锁钥学说**"发展到动态的"**诱导契合**"。

## ★ 专一性分类总图（背这棵树）
```
酶的专一性
├─ 结构专一性
│   ├─ 绝对专一性  只作用一种底物（脲酶只水解尿素；DNA聚合酶I）
│   └─ 相对专一性  作用一类结构相近底物
│        ├─ 族/基团专一性  对键一端基团要求严（α-D-葡糖苷酶要葡萄糖端）
│        └─ 键/反应专一性  只认某种键、不管两端基团（酯酶认酯键）
└─ 立体异构专一性
    ├─ 旋光异构专一性  只作用 L 或 D 之一（L-氨基酸氧化酶只作用 L）
    ├─ 几何异构专一性  只作用顺/反之一（琥珀酸脱氢酶只生成延胡索酸=反式）
    └─ A/B 型专一性  区分对称分子中等同基团（脱氢酶对 NAD⁺ 尼克酰胺C4的一侧）
```

## 一、结构专一性
- **绝对专一性**：只作用**一种**底物。脲酶只水解尿素；麦芽糖酶只作麦芽糖；DNA聚合酶I插错核苷酸概率 **<百万分之一**。
- **相对专一性**：作用**一类**相近底物，又细分——
  - **族/基团专一性**：对键**一端**基团要求严、另一端宽松（α-D-葡糖苷酶要求 α-糖苷键且一端是葡萄糖残基）。
  - **键/反应专一性**：只认某种**键**、对两端基团都不严（酯酶水解酯键，不管 R、R'）。

> ★ 蛋白酶专一性对比（消化道常考）：**胰蛋白酶** 切 **Lys/Arg**（碱性）羧基端肽键；**胰凝乳蛋白酶** 切**芳香族/大非极性**侧链羧基端；**弹性蛋白酶** 切 Ala/Gly 等**小侧链**；**胃蛋白酶** 切芳香族/疏水氨基酸的羧基或氨基端。**氨肽酶**切**氨基端**残基、**羧肽酶**切**羧基端**残基。

## 二、立体异构专一性
- **旋光异构专一性**：L-氨基酸氧化酶只氧化 L-氨基酸；β-葡糖氧化酶只作 β-D-葡萄糖。
- **几何异构专一性**：琥珀酸脱氢酶只生成**延胡索酸（反式）**，不生成顺丁烯二酸（顺式）。
- **A/B 型专一性**：脱氢酶对 NAD⁺ 尼克酰胺环 **C4 只认一侧加/脱氢**——酵母醇脱氢酶=**A型**（苹果酸脱氢酶、异柠檬酸脱氢酶同类）；异侧的=**B型**（谷氨酸脱氢酶、α-甘油磷酸脱氢酶）。
> 实践意义：药物常只有某一构型有效，酶可做**不对称合成或不对称拆分**。

## 三、★★ 解释专一性的两个假说（简答必背）
| | 锁钥学说（1894, E. Fischer） | 诱导契合（1958, Koshland） |
|---|---|---|
| 酶构象 | **刚性**，酶=锁、底物=钥匙 | 酶是**高柔性动态**分子 |
| 核心 | 结构互补是**固定的** | 底物**诱导**酶构象改变后再互补契合 |
| 缺陷/优势 | **不能解释逆反应**（同一刚性口袋难同时配底物和产物） | X 射线证实酶结合底物时**确有显著构象变化** |

> 记忆抓手：诱导契合 = "先变形、后配合"。它同时说明了**为何非专一性底物无效**——加个大基团或切掉基团都会顶歪催化基团 A、B，使其无法并列。诱导契合还有力支持了**过渡态的形成**。
