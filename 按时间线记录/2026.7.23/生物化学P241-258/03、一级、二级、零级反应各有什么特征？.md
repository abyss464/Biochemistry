【朱圣庚《生物化学》上册印刷第243-245页 · 第7章一、化学动力学基础（三）各级反应的特征】大纲层级：理解

各级反应的特征都藏在它们的速率方程里，把速率式**积分**、看浓度 c 随时间 t 的关系就能看出来。核心考点是三种级数的**半衰期**规律：一级半衰期与初浓度无关、二级与初浓度成反比、零级与初浓度成正比。半衰期 t₁/₂ 指有一半反应物转为产物所需的时间。

## 一级反应

- 速率只与反应物浓度的一次方成正比：−dc/dt = k·c，积分得 ln c = −kt + ln c₀，即 **ln c = ln c₀ − kt**。
- 以 ln c 对 t 作图得一条**直线**，斜率的负值就是速率常数 k；k 的单位是**时间的倒数**（s⁻¹）。
- **半衰期 t₁/₂ = 0.693/k**，与速率常数成反比、**与初浓度无关**——不管初浓度多少，半衰期都一样。这是一级反应的重要特征（放射性同位素常用半衰期表示衰变速率）。

## 二级反应

- 速率与反应物浓度的二次方（或两种物质浓度的乘积）成正比：−dc/dt = k·c²（或 k·c_A·c_B），是最常见的一类。
- k 的单位是 **mol⁻¹·L·s⁻¹**；把相应函数对 t 作图得直线、斜率即 k，可用来判定是否二级并求 k。
- 半衰期不仅与速率常数成反比，**还与反应物初浓度成反比**——初浓度越大、减少一半所需时间越短。

## 零级反应

- 速率与反应物浓度**无关**、只受其他因素（如酶被底物饱和）影响，速率为一常数：−dc/dt = k（即 x = kt）。
- k 的单位是 **mol·L⁻¹·s⁻¹**；以已反应量 x 对 t 作图得直线、斜率为 k。
- 半衰期与速率常数成反比、**与初浓度成正比**——初浓度越大、半衰期越长。

## 与酶动力学的衔接

这三种级数不是抽象数学：在米氏方程里会看到，**底物浓度很低时酶促反应表现为一级反应**（速率∝[S]），**底物浓度很高、酶被饱和时表现为零级反应**（速率与[S]无关，达 Vmax），中间是混合级——正因如此，测酶活力要在底物远过量、零级条件下进行（承接 P214-240 第12卡）。
