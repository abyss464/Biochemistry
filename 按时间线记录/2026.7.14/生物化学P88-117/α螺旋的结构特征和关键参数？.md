【印刷第100-101页 · 生物化学上册 第3章三(一)α螺旋】★★★必考·背熟参数

**α螺旋**是蛋白质中最常见、含量最丰富的二级结构。1950 年 **Pauling & Corey** 根据小肽晶体参数预测并命名。

## ★★关键参数（必背）
| 参数 | 数值 |
|---|---|
| 二面角 | φ=**-57°**，ψ=**-47°** |
| 每圈残基数 | **3.6 个残基/圈** |
| 螺距（pitch，每圈上升） | **0.54 nm** |
| 每残基沿轴上升 | **0.15 nm** |
| 每残基绕轴旋转 | **100°** |
| 直径（不含侧链） | 约 0.5 nm |
| 手性 | **右手螺旋**为主（左手极少，能量高） |

![[alpha-helix-key-geometry.svg]]

> 不要混淆“螺距”与“每残基上升”：一整圈上升 0.54 nm，一圈包含 3.6 个残基，所以每残基平均上升 0.15 nm。

## 氢键规律
- 由第 n 个残基的 **C=O** 与 N端方向第 **(n+4)** 个残基的 **N—H** 之间形成氢键；氢键方向**几乎平行于螺旋轴**。
- 氢键封闭成 **13 元环** → α螺旋又称 **3.6₁₃ 螺旋**。
- 含 n 个残基的螺旋有 **(n−4) 个氢键**（头 4 个 N—H 和末 4 个 C=O 不参与，可被"加帽 capping"）。

## 螺旋偶极（helix dipole）
- 每个肽键有偶极矩，沿轴同向排列 → **整个α螺旋是一个偶极**：**N端积累部分正电荷，C端部分负电荷**。

![[alpha-helix-hydrogen-bonds-dipole.svg]]

> 同一结构同时带来两个结果：主链 C=O(i)···H—N(i+4) 氢键沿轴稳定螺旋；肽键偶极沿轴叠加，使 N 端呈部分正电、C 端呈部分负电。

## 其他
- **协同性**：一旦形成一圈，后续残基加入变快（第一圈作模板）。
- 蛋白质中约 **1/4 的残基**以α螺旋存在；α-角蛋白中占优势。
