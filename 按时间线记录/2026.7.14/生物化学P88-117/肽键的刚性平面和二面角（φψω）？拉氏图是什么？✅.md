## 肽键的刚性平面
- 肽键（C—N）是**共振杂化体**，具**部分双键性质**，不能绕键轴自由旋转。
- 与肽键关联的 **6 个原子**（Cα—C(=O)—N(H)—Cα）共处一个平面 → **肽平面/酰胺平面**；C=O 与 N—H 呈**反式**。
- 主链上只有 **Cα 连接的两个键**（Cα—N 和 Cα—C）是纯单键、能自由旋转；Cα 是相邻两肽平面的旋转点。

![[peptide-bond-rigid-plane.svg]]

> 共振使 C—N 肽键获得部分双键性质，因而“不易转动”；结果是 Cαᵢ、Cᵢ、Oᵢ、Nᵢ₊₁、Hᵢ₊₁、Cαᵢ₊₁ 六个原子被限制在同一肽平面内。

## 三个二面角（扭角 dihedral angle）★
| 二面角          | 绕哪个键旋转      | 范围/特点                                     |
| ------------ | ----------- | ----------------------------------------- |
| **φ（phi）**   | Cα—**N** 键  | -180°～+180°                               |
| **ψ（psi）**   | Cα—**C** 键  | -180°～+180°                               |
| **ω（omega）** | **C—N（肽键）** | 因肽键平面性，限于 **±180°（反式，占 99.6%）**，极少 0°（顺式） |

- 完全伸展时 φ=ψ=±180°；φ=ψ=0° 的构象**不能存在**（相邻肽基 H 与 O 空间位阻，距离 < 范德华半径之和）。

![[peptide-backbone-dihedral-angles.svg]]

> 定位方法：以中间的 Cαᵢ 为基准，向 N 端的 Nᵢ—Cαᵢ 是 φ，向 C 端的 Cαᵢ—Cᵢ 是 ψ；再向右的 Cᵢ—Nᵢ₊₁ 肽键对应 ω。

## ★拉氏图（Ramachandran plot）
- 印度学者 **Ramachandran G N** 把肽链原子看成硬球，按范德华半径定出非键合原子最小接触距离，判断哪些 (φ, ψ) 组合**被允许/不允许**。
- 以 φ（横）对 ψ（纵）作图 → **拉氏构象图**；每个点=一个 Cα 的一对二面角=一种局部构象。

![[ramachandran-plot-allowed-regions.svg]]

> 先看横纵坐标确定残基的 (φ, ψ)，再看该点是否落入绿色允许区。区域边界为示意：甘氨酸的允许区更广，脯氨酸更窄。

- 实测约 1000 个非甘氨酸残基的 φ、ψ 值都落在**允许区**内 → 验证了肽链折叠的立体化学限制。
