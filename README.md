## 每日固定流程

1. 若存在未批改的 `卷子 完成.md`，先生成 `卷子 批改.md`。
2. 按计划取得当天教材印刷页码范围。
3. 使用 `/Users/abysser/Documents/Code/kiz/RAG/scripts/page_lookup.py` 逐页读取整个范围；跨页内容补取相邻页。
4. 覆盖页面中的全部小标题、定义、机制、公式、表格、数字、例外、比较和可考例子，并按官方考纲确定讲解深度。
5. 按教材自然知识单元拆成问题式 Markdown 考点卡，一个完整复习主题一文件；卡片先于卷子生成，不与卷子逐题一一对应。从2026.7.21批次起，每个科目目录按阅读顺序独立编号，文件名统一为`01、问题式考点.md`。
6. 汇总当天考点生成不含答案的 `卷子.md`。
7. 用户复制为 `卷子 完成.md` 并闭卷作答。
8. 下一轮批改，提取硬错和回炉项，然后再推进新页。

卡片可以支撑多道名解、填空、判断和简答；一道综合题也可以跨多张卡片。文件名或一级标题应便于找到主要概念，但不能为了迁就卷子把完整教材主题切成零碎小卡。若页码边界截断同一小节，则补取相邻页直至该小节结束，并在卡片上标明实际引用页码；补取页只用于闭合主题，不提前计算计划进度。

每张卡应先给出可闭卷复述的“总答/因果链/步骤主线”，再按定义、机制、结果、例子或比较展开。公式、数字和例外必须挂在相应概念下，不能把逐页覆盖清单原样堆成卡片。生成后须逐张从头重读，确认只看标题即可沿主线口述答案。

## 目录格式

```text
按时间线记录/YYYY.M.D/
├── 生物化学P起-止/
│   ├── 01、问题式考点.md
│   └── 02、问题式考点.md
├── 普通生物学P起-止/ 或 遗传学P起-止/
│   ├── 01、问题式考点.md
│   └── 02、问题式考点.md
├── 卷子.md
├── 卷子 完成.md
└── 卷子 批改.md
```

编号按教材印刷页码和学习逻辑确定，各科目目录均从`01`开始，必须连续且不得重号。卡片顺延到新日期时，按目标目录的阅读顺序重新编号；`✅` 由用户在复习完成后添加，顺延改名时须保留，生成资料时不自动添加。2026.7.21之前的历史批次不追溯改名，除非用户明确要求。

遇到像612 P214–451这样已经通读、但尚未卡片化和闭卷验证的大范围积压时，不建立一个超大页码目录。按当前每日页数和自然小节拆成多个连续的`生物化学P起-止/`目录，每个目录从`01`编号并配一张独立分卷。逐页检索和知识覆盖仍针对完整范围执行；拆目录只改变学习与验收颗粒度，不允许省略低优先级页面内容。

## 五批次综合复盘

- 每完成5个实际学习批次，下一可用学习日不开新页，改做一次五批次综合复盘。
- 按学习批次计数，不按自然日计数；纯复盘日不计入下一组5批次。
- 综合卷固定覆盖这5批次的612与888全部页段，同时强化历次批改中的硬错，但不能只出错题。
- 被复盘占用的当日页码批次整体顺延一天，优先用缓冲日吸收，保留用户答案、`✅`和部分完成状态。
- 每次复盘日在`学习安排.md`中记录所覆盖的5个日期，避免重复计数。
